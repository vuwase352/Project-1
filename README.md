# Project-1

## Objective
- Identify the top 5 locations with the highest mean/median concentrations of VOC, PM 2.5, and PM 10.0.
- Determine the specific dates of maximum pollutant concentrations and research potential causes.
- Analyze the correlation between Temperature/Humidity and air quality using specific categorical bins.
- Identify instances where air quality exceeded EPA AQI health risk thresholds.

## Methods
- Pandas: For data cleaning, binning, and statistical aggregation.
- Matplotlib/Seaborn: For visualizing air quality trends and hotspots.
- NumPy: For numerical calculations and handling maximum value identification.

## How to Run
1. Open analysis.ipynb in Jupyter Notebook
2. Ensure the CSV file is in the same directory
3. Run all cells from top to bottom
